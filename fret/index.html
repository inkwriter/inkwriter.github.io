FRETKIT

guitar utility hub

Tuner

Pick a tuning, then pluck each string button and match your guitar to it by ear. Strings run low (thick, top) to high (thin, bottom) — string 6 down to string 1.

Custom Tuning

Build your own tuning. Pick a note and octave for each string, test it, name it, and save it. Saved tunings show up in the Tuner and Tab Player.

Saved tunings

Tab Player

Paste a standard six-line guitar tab and press play. Each character column is one sixteenth-note step. Notes stacked in the same column play together as a chord.
