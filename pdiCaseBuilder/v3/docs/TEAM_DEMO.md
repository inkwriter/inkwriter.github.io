# Team Demo Script

## 1. Start on Home
Point out:
- Guided Mode is the default.
- Case evidence stays local unless deliberately exported/copied.
- Known patterns are sanitized and do not expose real tickets/screenshots.

## 2. Load the Double-close demo
Choose **Double-close fingerprint**.
Show how the site explains the GT relationship and labels it a **Strong Known Pattern**, while still requiring DRPOS/surrounding-day verification before any correction.

## 3. Load the Missing-XML demo
Show that the site distinguishes:
- Store Close completed;
- expected poll XML missing;
- repeating Store Close is specifically guarded against.

## 4. Switch to Technician Mode
Show the complete evidence workspace and GT fields without making that complexity the default experience for the rest of the team.

## 5. Copy for ChatGPT
Explain that the handoff summarizes the case and tells ChatGPT to use the private PDI Support Playbook, ask for the highest-value missing evidence, and avoid advanced changes without support.

## 6. Finalize a case
Show the root-cause confidence, verification checklist, and **Was the Case Builder suggestion accurate?** field. This is how v3 will be measured and improved.
