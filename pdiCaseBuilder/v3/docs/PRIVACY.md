# Privacy and Data Boundary

## Public GitHub / GitHub Pages
Safe to store:
- application code;
- sanitized pattern packs;
- evidence schema;
- synthetic demo cases;
- synthetic pattern tests;
- documentation that contains no sensitive internal data.

## Private company storage
Keep private:
- original closed-ticket exports;
- curated historical case records with real stores/tickets/dates;
- case-to-pattern source map;
- screenshots from real incidents;
- exported real case reports;
- private PDI playbook/SOP material that should not be public.

## Browser-local data
The Case Builder uses IndexedDB for cases and attached screenshots. A user's local cases are not automatically shared with another technician or browser. Use the archive export/import functions for controlled transfer or backup until a company-approved shared backend is introduced.
